# 0.8 POC 验收矩阵

> 适用于 0.8 的内部实验，不构成公共 API 发布标准。任何一项缺少真实环境证据时，POC 必须留在 `src/experimental`。

| POC | 已覆盖的自动化边界 | 本地 Chrome | 真实环境仍需记录 | 失败时处理 |
| --- | --- | --- | --- | --- |
| Virtual scrolling | 固定行高、窗口上限、滚动替换、空态、容器焦点 | 320px 窄宽与连续滚动冒烟 | Safari、VoiceOver/NVDA、性能面板、真实嵌入容器 | 保持内部 POC；不接入 `Table` |
| Sticky header / column | start/end offset、stacking、横向容器、焦点 | 320px 横纵滚动 | Safari、RTL、popover 裁剪、V1 selection/sorting | 保持内部 POC；不接入 `Table` |
| Column resize / reorder | 宽度上下界、顺序更新、键盘控制 | 基础受控重排冒烟 | 键盘拖拽、持久化、真实列 schema 迁移 | 保持内部 POC；不改变声明式列 API |
| Expandable row / inline edit | 展开、校验、保存、冲突、取消 | 基础展开焦点与受控保存冒烟 | 焦点回收、读屏、真实写入权限与撤销 | 保持内部 POC；写入继续由应用控制 |
| Cursor infinite loading | cursor 去重、终止、失败恢复、加载状态 | 两页加载、去重和终止状态冒烟 | 真实 cursor API、快速重复触发、网络取消 | 保持内部 POC；不混入 offset query |

## 统一退出规则

- 任何候选能力都不能改变 V1 `Table` 的默认 DOM、查询或选择语义。
- 公开 opt-in API 仅在对应 POC 完成自动化测试、Storybook、设计记录、目标浏览器/容器和辅助技术验证后评审。
- 未通过的 POC 可以保留为实验记录，但不得在 CHANGELOG 中宣称为已发布能力。

## 本轮执行说明

- Chrome 已完成 Virtual scrolling 的 20 次连续滚动压力冒烟：在 12,800px 位置仍只挂载 14 行，未观察到 DOM 节点随总数据量无界增长。
- Safari 本地 Storybook 已覆盖五项 POC 的核心交互；真实嵌入容器、VoiceOver/NVDA、性能 trace 与真实服务端契约仍是发布门槛。
