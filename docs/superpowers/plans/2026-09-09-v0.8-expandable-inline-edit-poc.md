# 0.8 Expandable Row / Inline Edit POC

> 状态：实现完成，真实环境验收中。此 POC 不构成公共 API 或发布承诺。

## 目标与范围

验证单个可展开详情区与一个版本化内联字段能否保留明确的受控写入边界。实现位于 `src/experimental/ExpandableInlineEditPOC.tsx`，不从包入口导出；它复用框架无关的 `expandable` 与 `inlineEdit` 状态 helper，但不绑定 V1 `Table`、服务端或真实授权模型。

| 项目 | POC 决策 |
| --- | --- |
| 展开状态 | 调用方受控提供 `expandedIds`；组件只请求 `onExpandedIdsChange` |
| 焦点 | 展开后将焦点移至新出现的详情 region；折叠时不实现完整的触发器焦点恢复 |
| 编辑草稿 | 组件内部保存单字段 `name` draft；取消直接丢弃草稿 |
| 写入 | `onSave` 收到 `rowId`、draft 与 optimistic version；组件绝不本地修改 `rows` |
| 校验 | 提交前同步校验；字段错误以 `aria-invalid`、`aria-describedby` 与 alert 提示 |
| 冲突 | host 返回新 version 时保留 draft 并明确提示；不会悄悄覆盖 canonical row |
| 回滚 | 取消或失败不改变调用方提供的 canonical rows |

## 验收指标

- React 测试验证展开状态受控、详情区获得焦点、校验失败不写入、取消回滚草稿、以及带 version 的受控保存请求。
- Storybook 手动检查 Tab 顺序、展开后焦点位置、错误朗读、保存 pending 与 conflict 提示；再以真实宿主实现持久化和授权。
- 若出现焦点丢失、展开详情破坏表格导航、冲突覆盖数据、异步保存竞态或读屏顺序错误，则保持为内部 POC，不接入公共 `Table`。

## 当前验证记录

- **自动化 React 测试：通过。** 覆盖受控写入、校验、冲突、取消与展开焦点。
- **Chrome 本地 Storybook：通过基础展开/保存冒烟。** 展开 Ada 的详情后该 region 获得焦点；保存受控草稿后 host 更新 canonical row，组件显示成功状态并关闭草稿会话。
- **Safari 本地 Storybook：通过基础展开/保存冒烟。** 展开详情后 region 获得焦点；保存 Ada Safari 后 host 更新 canonical row，显示成功状态且编辑器关闭。
- **待验证：** VoiceOver 真实听读、真实嵌入容器的 focus/stacking 行为、host 的授权/持久化/冲突策略，以及多字段、批量编辑与虚拟化组合。

## 已知限制与回滚

此实验不支持多单元格编辑、ESC/Enter 快捷键、焦点恢复、嵌套可展开行、row selection、sticky/virtual renderer 组合、离线重试或服务端权限提示。回滚只需删除 `src/experimental/ExpandableInlineEditPOC.tsx`、对应测试和 Storybook 示例；V1 `Table` 与现有 V3 helper 不受影响。
