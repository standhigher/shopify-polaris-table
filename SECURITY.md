# Security Policy

## Supported versions

Security fixes are applied to the latest release on `main`. Older releases may not receive patches.

## Reporting a vulnerability

Please use a [private GitHub security advisory](https://github.com/standhigher/shopify-polaris-table/security/advisories/new) to report a suspected vulnerability. Do not open a public issue and do not include credentials, tokens, customer data, or other secrets.

Include a clear description, affected versions, reproduction steps, and the potential impact. Maintainers will acknowledge reports and coordinate a fix through the advisory when appropriate.
